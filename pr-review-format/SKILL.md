# PR review format

This skill is reference material for `receiving-review` and `review-teammate-pr`.
Those skills link to these files directly, so install all three together.

- [Chat format](references/chat-format.md): the card layout and the rules for every
  turn.
- [Grounding](references/grounding.md): the research behind every fix direction,
  finding, and decline.
- [Agent disclosure](references/disclosure.md): the first line of every posted
  comment or reply.
- [GitHub commands](references/github.md): fetching threads, replying, resolving, and
  posting reviews.
